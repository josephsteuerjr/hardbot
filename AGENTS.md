# Память проекта

Перед работой прочитай `PROJECT_MEMORY.md`. Локальные операционные сведения и
список участников теста находятся в `_local/PROJECT_MEMORY.md` (вне git).
Сверяй память с текущим кодом: старые архивы описывают прежние решения.

Не помещай персональные данные, ключи, ссылки входа, реальные реестры или
снимки рабочей БД в отслеживаемые файлы. Для них используется `_local/`.
