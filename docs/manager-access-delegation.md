# Подтверждение входа команды

С 02.11.2026 текущий руководитель подтверждает регистрацию, повторный вход и
устройства своих сотрудников в «Входе команды». После сброса временного пароля
сотрудник сначала задаёт личный пароль, затем руководитель подтверждает его
устройство. Дополнительное решение владельца не требуется.

На каждом действии сервер заново проверяет действующую команду, активный штат и
роль. Нельзя подтвердить себя, другого руководителя, отключённого сотрудника,
отозванное устройство или чужую команду. Для ПК сохраняется подписанная проверка
установки и личная сверка сотрудника за компьютером; для телефона — сверка личности.
Сброс отзывает прежние сессии; повтор того же operation_id не меняет пароль снова.

Проверенный сброс пароля руководителя владельцем (root CLI либо активный
ssh-root principal) одновременно разрешает следующий вход на одном ПК и одном
телефоне. Разрешения одноразовые, расходуются после успешной проверки пароля и
установки, записываются в журнал. Личный пароль по-прежнему обязателен. Обычный
сброс оператором такого разрешения не выдаёт. Отключение аккаунта отменяет
неиспользованные разрешения. Первичная выдача привилегированной роли и
восстановление первичного профиля владельца сохраняют прежний порядок.

При установке серверного обновления существующие аккаунты и устройства не
активируются массово; бизнес-данные и текущие пароли не меняются.
