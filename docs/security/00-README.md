## Резюме для ИБ за 60 секунд

- **Локализация ПД закрыта дизайном:** реальные данные должников живут только он-прем на
  машине аналитика/сервере филиала; демо-сервер — **только синтетика, ПД там не бывает**.
- **Аутентификация миниаппа — честная:** HMAC-SHA256 подпись Telegram WebApp (`initData`),
  constant-time сравнение, свежесть 24 ч. Подделка/просрочка отвергаются (есть тесты).
- **Закрытые в O3 бреши:** (а) auth-токен на API движка + запрет отдавать реальную БД без
  токена; (б) **аппрув привязки выездника** владельцем; (в) сужен CORS; (г) каркас аудит-лога.
- **Регуляторика как код:** лимиты 230-ФЗ (≤1 визит/нед, часы 08–22/09–20) — жёсткие
  ограничения оптимизатора, не пожелание.
- **Остаётся для go-live (must):** TLS-инвентаризация, шифрование диска на проде, MFA на
  привилегиях, ротация секретов, **независимый пентест** (см. §14), формализация retention.
