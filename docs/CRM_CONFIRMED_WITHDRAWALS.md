# Подтверждённые отзывы и отчёты СНГ

Подтверждённый отзыв хранится в PostgreSQL отдельно от закрепления и полей Excel. Рабочие очереди звонков, выездов и доставки исключают отозванный договор. Сервер проверяет статус при сохранении результата и при новом назначении, включая действия из старой открытой карточки. История операций доступна по обычным правам. Обычный импорт портфеля и восстановление закрепления не меняют подтверждённый статус.

## Подтверждение статуса

Уполномоченный оператор формирует список из проверенной выгрузки с полями `legacy_id`, `creditor_id`, `day` в формате ISO, `source`, `sha256` файла и `withdrawn`. Для источников, которые используют один номер в разных входах, до подготовки списка проверяется дата входа. Для возврата в работу требуется явное более позднее подтверждение с `withdrawn=false`.

Команда `python tools/crm_runtime.py contact-status --evidence <file>` проверяет договоры и кредиторов и возвращает хеш списка. Для записи передать тот же список и `--expected-sha256 <hash>` через операционный доступ в PostgreSQL. Повтор того же свидетельства идемпотентен. Второе несовпадающее свидетельство за тот же день требует сверки до записи. Старые отметки в Excel, отсутствие договора в файле и заявки на отзыв без подтверждения сами по себе статус не меняют.

20.11.2026 подтверждены и закрыты для работы 716 договоров «А-Деньги» и 367 договоров ЗК. Проверка публикации обычного импорта на копии рабочей базы показала, что старое закрепление и пустые поля отзыва не возобновляют работу. Для остальных отметок требуется подтверждение по источникам. Операционные квитанции и резервные копии сохранены вне Git.

## Сводки Excel

`tools/refresh_common_reports.py` открывает общий реестр для чтения, последовательно пересчитывает «Статистику общего реестра» и «Статистику по КА общего реестра» и готовит выпуск «— знач». Книги сохраняются через Excel, контрольные чтения выполняются через calamine.

Для теста указать `--master`, `--reports` и локальный каталог `--journal`. Для сохранения в рабочих книгах добавить `--apply`. Запускать после сохранения очередной версии общего реестра. При занятой книге «— знач» подготовленный выпуск и исходные контрольные копии остаются в локальном каталоге запуска. Два отчёта со связями проверяются независимо.
