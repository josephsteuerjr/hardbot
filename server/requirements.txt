#
# Почему так. Этот файл едет чужой ИТ-службе вместе с исходниками и живёт там
# годами. С «>=» один и тот же архив, собранный сегодня и через полгода, даёт

# повторяемой: собрали, проверили, увезли.

# Второй ряд (зависимости зависимостей) запинен тоже — иначе «плавает» именно

# приложение поднялось и отвечает на HTTP.
#

# перенести сюда. Не редактировать «на глазок» — второй ряд связан с первым.
#
