# Выезды · Пульт

**Десктопный пульт аналитика на Python + PySide6 (Qt 6) + Excel.** Запуск:
двойной клик по `Пульт.pyw` (без консоли — расширение `.pyw` открывается через
`pythonw`/`pyw`) или `python pult.py`. High-DPI — штатный Qt 6. Разделы:
Сводка / Реестр / Приоритет / Люди / Руководители / Активность / Подключение.

Любая ошибка при старте (нет PySide6, нет папки `server` рядом, битые
модули) показывается окном с причиной, а не тишиной.

## Структура

| Файл / папка | Назначение |
|---|---|
| `Пульт.pyw` | Точка входа двойным кликом, без консоли |
| `pult.py` | Совместимая обёртка: `python pult.py` поднимает то же окно; реэкспортирует прежние имена (`Pult`, `LIMITED_TEST_*`, `write_registry_xlsx`…) для документов и тестов |
| `app.py` | Сборка QApplication, тема, окна ошибок старта |
| `core/` | Логика без Qt, покрыта тестами: `settings.py` (тот же файл настроек), `api.py` (клиент admin-API: X-Device-Token/X-Admin-Key, дружелюбные ошибки, TLS-fallback), `registry_import.py` + `import_flow.py` (книга → выбор сотрудников → предпросмотр → применение), `export.py`, `enrichment.py` (подбор личных файлов, окно дат, реестр доставленного, отчёт), `devices.py`, `managers.py`, `people.py`, `activity.py`, `priority.py`, `dashboard.py`, `workbook.py`, `text.py` |
| `ui/` | PySide6: `theme.py` (токены + QSS), `widgets.py`, `nav.py` (рейка с SVG-иконками), `tasks.py` (QThreadPool), `dialogs.py`, по модулю на раздел, `main_window.py` |
| `enrich.py` | Библиотека доказуемого обогащения: пишет только proven bot-поля, ведёт реестр доставленного, проверяет snapshot/file map/contract, сохраняет ручной текст и создаёт backup |
| `limited_test_import.py` | Узкий двухфазный CLI для опубликованного master и утверждённого `test_subset` |
| `razbros.py` | **LEGACY, запись заблокирована.** Старый разброс оставлен для анализа/предпросмотра |
| `repair_false_enrichment.py` | Двухфазная точечная починка старых артефактов ложного обогащения |
| `icon.png` | Иконка окна (если файла нет — окно без иконки) |
| `настройки пульта.json` | Адрес сервера, токен устройства, последние папки — создаётся сам |
| `PORT_CHECKLIST.md` | Инвентаризация Tk-пульта и чек-лист приёмки порта на Qt |

## Зависимости

```powershell
pip install -r pult\requirements.txt
```

`PySide6==6.11.2`, `python-calamine` (чтение реестров), `openpyxl` (экспорт
xlsx), `xlwings` + `pywin32` + установленный Excel (обогащение `.xlsb`).
Сеть — стандартная библиотека. Папка `server/` должна лежать рядом с `pult/`:
пульт берёт оттуда контракт обмена и схему полей.

## Реестр: импорт, обогащение, слепок

- **Импорт опубликованного master** — единственный штатный вход в бота.
  После выбора файла пульт отмечает только сотрудников, у которых уже есть
  портфель в БД (в пустую БД — весь файл); фильтр «есть в БД» возвращает этот
  выбор. Кнопка «Предпросмотр» ничего не пишет: сервер отдаёт точные
  множества эффектов с digest, и только тогда открывается «Применить импорт».
  Пульт fail-closed по каждому эффекту (снятия, возвраты, комментарии, отзыв):
  без digest от сервера применение не начинается. Если ручка регистратора на
  сервере закрыта, пульт печатает команду регистрации proof.

- **Возврат вручную снятых договоров** — отдельная галочка импорта. Обычный
  импорт не воскрешает снятые в пульте кейсы; с галочкой preview показывает
  точный состав, apply принимает только совпавшие count+SHA-256.

- **Обогащение личных реестров** — точечно переносит доказанные визиты бота
  в личные `ФИО.xlsb`. Окно дат выезда предзаполняется из последней квитанции;
  пустое окно требует явного подтверждения «вся история». Сервер ведёт
  **реестр доставленного** — что именно пульт сам положил в книгу, — поэтому
  правка офиса поверх доставленного распознаётся и не затирается; отличия,
  которые нельзя объяснить, попадают в таблицы «Конфликты» и «Правки офиса» и в
  отчёт. Галочка «Считать сервер источником для строк без истории доставки»
  выключена по умолчанию и нужна только для первого прогона по новой книге.
  Если сервер был недоступен в момент прогона, реестр можно дослать кнопкой
  «Повторить отправку из квитанции». Резервные копии и квитанции —
  в `<база>/!! Обогащение из БД`.

- **Экспорт-слепок** — новый xlsx из БД сервера (типизированные даты/суммы,
  автофильтр), весь реестр или выбранные сотрудники, с окном доказанных
  выездов. «Метки курьеров…» — отдельный xlsx.

- **Период выгрузки**, **Отозванные договоры** — как раньше.

Что закрыто и должно оставаться закрытым: сброс базы из пульта (обходит
snapshot/export/clearance) и загрузка личных книг в бота (personal ↔ master
обслуживает только `registry_cycle`).

## Подключение

Мастер-ключ вводится один раз — «Привязать это устройство» обменивает его на
токен машины, ключ на диске не остаётся. Подробно: `УСТРОЙСТВА.md`.

## CLI-пути (без окна)

Двухфазный импорт `limited_test_import.py` (prepare-published-master /
prepare → register на сервере → apply) и починка `repair_false_enrichment.py`
описаны в докстрингах модулей; поведение не менялось.
