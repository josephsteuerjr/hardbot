## 5.2. RBAC-матрица (least privilege)

Роли в системе (фактические, из `config.is_trusted` / `agent_bind`):

| Роль | Кто | Идентификация |
|---|---|---|
| **Выездник/Курьер** | граждане СНГ, полевые | telegram_id + approved-привязка к «Сотруднику» |
| **Аналитик/Владелец (ADMIN)** | Егор | `ADMIN_ID` (env) |
| **Система (демо)** | витрина | синтетика, без ПД |

| Действие | Выездник | Курьер | ADMIN |
|---|:--:|:--:|:--:|
| Видеть СВОИХ должников (`responsible==employee`) | ✅ | ✅ | ✅ (всех) |
| Видеть ЧУЖИХ должников | ❌ | ❌ | ✅ |
| Открыть карточку (аудируется) | свои | свои | все |
| Фиксировать выезд / save | свои | свои | все |
| Ставить GPS-метку | свои/свободные | свои/свободные | все |
| Импорт/экспорт реестра | ❌ | ❌ | ✅ (`X-Admin-Key`) |
| Менять веса скоринга, период | ❌ | ❌ | ✅ |
| **Одобрять привязку** | ❌ | ❌ | ✅ |
| Доступ к API движка (ПД) | ❌ | ❌ | ✅ (`ENGINE_API_TOKEN`) |
| Читать аудит-лог | ❌ | ❌ | ✅ |

**Принцип least privilege соблюдён:** выездник технически ограничен своими записями
(`clients_for_employee` + проверка на каждом эндпоинте), а не «по договорённости».
Разница agent/courier — только в выгрузке, не в правах доступа.
