ХАРД / СОФТ — КАК НАЧАТЬ (версия 2.0.4)

1. Скопируйте архив программы из своей рабочей папки на свой компьютер,
   например на локальный рабочий стол. Для Софта он называется
   «Программа СОФТ.zip». Нажмите правой кнопкой по архиву → «Извлечь всё».
   Откройте извлечённую папку и запустите «Хард.exe»; ресурсы рядом нужны.
   Запускайте приложение из этой локальной папки. Из окна архива и с сетевого
   диска программу не запускайте. Установщик, Python и Excel для неё не нужны.

2. Вставьте свою личную ссылку входа от руководителя («Вход команды»)
   или аналитика. Ссылка определяет сотрудника и доступные режимы.
   Первое подключение требует сети. После него вход сохраняется на этом ПК.
   Свою ссылку не передавайте другим и не сохраняйте в общей папке.

3. Одна ссылка позволяет два входа для телефона (браузер и ярлык)
   и один отдельный вход для программы на ПК. Копирование прежней ссылки
   и повтор с действующим входом квоту не расходуют. ПК не отключает телефон.
   Истёкшую/исчерпанную ссылку перевыпускает руководитель/аналитик.
   Перед новым входом убедитесь, что не осталось неотправленных результатов.

4. Софту: откройте «Кому звонить». «Сегодня» показывает перезвоны на сегодня,
   просроченные и дела без статуса/даты; «Все» — весь портфель. Поиск и
   сортировка доступны в таблице. В карточке видны контакты, договоры,
   прежний комментарий и история. Выполните звонок обычным способом,
   выберите результат, следующий контакт и при необходимости обещание.
   В «Новой заметке» пишите только новый текст: он допишется с автором
   и временем. Пустая новая заметка прежний текст не стирает.

5. «Сохранить звонок» фиксирует результат в журнале, само приложение
   не набирает номер. Без сети результат сохраняется в защищённую очередь
   этого ПК и отправится при восстановлении связи. «Ожидает отправки»
   означает, что сервер ещё не принял запись. Ошибки требуют проверки;
   удаляйте запись из очереди только после понимания причины.

6. Выезднику: на ПК — портфель, текущий комментарий и чеки. Выезд
   завершается в телефоне. Чек можно приложить по своему договору
   в обоих режимах: укажите сумму и дату из чека, если платил другой — кто.
   Чек сам по себе не означает, что деньги зачислены.

7. Руководителю/СБ: та же программа открывает пульт по вашей ссылке.
   Руководитель видит активность, команду, обещания, отчёты и выдаёт вход.
   СБ дополнительно видит «Контроль»: проверку выездов, результаты Софта,
   закрепления и доступ. Результат звонка — запись сотрудника, требующая
   независимого подтверждения при расследовании.

8. Закрытие окна сворачивает программу к часам Windows. Чтобы завершить
   её полностью: правой кнопкой по значку → «Выход». После обновления
   нужна такая полная перезагрузка. Не удаляйте данные приложения ради
   исправления связи: там может находиться неотправленная очередь.

9. При смене компьютера/увольнении попросите аналитика отозвать доступ.
   Штатная кнопка выхода очищает локальный вход и очередь после подтверждения.

Аналитику: ваша копия находится внутри комплекта рядом с pult/ и server/.
Она требует Python и зависимостей пульта; комплект сотрудника их не содержит.
