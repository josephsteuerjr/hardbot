## 19.10.2026 — Windows3.2.5 / PWA101

Обновления Windows скачиваются автоматически после проверки прежним Ed25519 ключом. Установка запускается явной кнопкой «Перезагрузить для установки обновления»; внешний мастер передаёт native NSIS флаг повторного запуска. Валидные зашифрованные очередь и черновики допускаются к обновлению и сохраняются. Открытую изменённую форму нужно сохранить.

Веб-оболочка предлагает явную кнопку обновления и сохраняет черновик/очередь. На iPhone/Android14 часов отсчитываются от последнего подтверждённого контакта с сервером. После срока удаляются все локальные данные профиля, включая неотправленные записи/фото/черновики/токены/кэши. Исключения для неотправленного нет. При возобновлении очистка выполняется до показа или отправки старых данных. На Windows этот срок не распространяется.

Синхронизация показывает настоящие подтверждения сервера, отправлено/осталось, ошибки и паузы; состояние сохраняется при перезапуске. Удаление по сроку или отзыву не считается успешной синхронизацией. До отправки очереди проверяется действительность доступа. Ожидание подтверждения/смены первого пароля отличается от отзыва. Руководитель без команды имеет действительную собственную identity.

В Аналитике отдельная кнопка «Удалить аккаунт» удаляет серверный аккаунт и регистрации устройств, отзывает все сессии и сохраняет отправленные рабочие факты/аудит. Блокировка — отдельное действие. Первичный профиль владельца защищён; подтверждение удаления привязано к поколению account_id.

Strict latch, server/account_policy.py и server/data_exchange_contract.json не менять; старый ключ подписи сохранять. Персональные данные, приватные ключи, входы и реальные базы находятся только в _local/ вне git. Не повторять операционные изменения по историческим журналам без проверки квитанций.

Проверки: полный прогон2767 без failures/errors,32 skips; последняя identity-поправка18/18. Четыре готовых Windows EXE проверены по фактическим вложенным исходникам и runtime, окна/IPC/frozen backend проверены. Реальные QA установщики прошли скачивание, кнопку, native установку, повторный запуск и сохранность DPAPI queue/draft/token. Chromium Android/ПК и WebKit iPhone прошли SW/offline/restart/sync/новую оболочку. Физические телефоны и установленная мобильная PWA не проверены. PWA.install отсутствует в доступном CDP; этот сценарий не объявлять пройденным.

Дополнительная защита повторной регистрации: удалённый внутренний ID сотрудника никогда не выдаётся новому аккаунту. Сохранившаяся legacy-привязка не переносит старую очередь на новую учётную запись; рабочие факты и бизнес-закрепления сохраняются. Явное повторное назначение удалённого ID отклоняется. Четыре дополнительных сценария проверяют наследование, коллизию allocator, отказ старому UID и сохранность портфеля.
