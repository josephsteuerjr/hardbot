# Каталог модели распознавания речи

Сюда `python tools/prepare_stt_model.py` кладёт готовую модель, а
`stt/Dockerfile` запекает её в образ по пути `/opt/hard/stt-model`.

В репозитории каталог пустой — веса в git не хранятся. В ПОСТАВКЕ он пустым
быть не должен: пустой каталог означает, что на объекте служба речи не
поднимется, потому что качать модель из интернета ей запрещено.

Что здесь появляется после подготовки:

| Файл | Что это |
|---|---|
| `model.bin` | веса в int8, ≈ 0,82 ГБ |
| `config.json`, `tokenizer.json`, `vocabulary.json`, `preprocessor_config.json` | словарь и настройки, как в исходной модели |
| `hard-model.json` | манифест: имя модели, откуда взята, точность, размеры и SHA-256 |
| `SHA256SUMS` | те же суммы в обычном формате `sha256sum -c` |

Проверить, что модель на месте и довезена целиком:

```bash
python tools/prepare_stt_model.py --verify
```

Этот файл каталог и держит: без него git не сохранил бы пустой каталог, а
`docker build` спотыкался бы на `COPY model` ещё до того, как кто-нибудь дошёл
бы до модели.
