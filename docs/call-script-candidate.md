# Кандидат скрипта звонка — 3.2.21-rc.1

В программе руководителя появился «Скрипт звонка»: название, до 12 шагов с
заголовками и текстом, предпросмотр, сохранение черновика, публикация и снятие
публикации. Несохранённые правки отмечены и сохраняются при переключении разделов
в пределах текущего сеанса; для сохранения между запусками нужен «Сохранить черновик».

Сотрудник Софта видит опубликованный текст своего текущего руководителя слева от
карточки звонка. Скрипт и форма прокручиваются независимо. Кнопка «Портфель»
возвращает таблицу; «Скрипт звонка» в карточке открывает подсказку снова.
Открытый текст не меняется внезапно во время разговора: новая публикация
загружается при открытии карточки или через «Обновить скрипт». Ошибка обновления
сохраняет показанную версию. Заметка к звонку при этом не перерисовывается.

Доступ и команда проверяются сервером заново при каждой операции. Получатель
определяется действующим штатом, продуктом soft и явным manager_uid; широкая
региональная область другого руководителя не подменяет своего руководителя.
Неопределённый руководитель означает отсутствие скрипта. Черновики не выдаются
через API сотрудника. HTML показывается как обычный текст. Revision защищает от
перезаписи из другого окна, operation_id делает повтор потерянного ответа безопасным.

Это отдельный кандидат: API и интерфейс скрипта не входят в стабильный 3.2.20.
Проверка: `python -m pytest tests/test_call_scripts.py`; из `hard-desk` —
`node build.mjs`, `python tools/test-call-script-http.py`. Последняя команда
создаёт временную SQLite, настоящий loopback API и окна Electron с тестовыми
CRM-данными, проверяет весь цикл и сохраняет PNG. Рабочие профили не используются.
`pythonw tools/test-call-script-http.py --preview` открывает два демонстрационных
окна с тестовой публикацией; закрытие обоих завершает локальный API.
