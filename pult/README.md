# Пульт «Контур · Выезды»

**Актуальный пульт — `pult.py` (Python/Tkinter).** Запуск: двойной клик
`Пульт.bat` (или `python pult.py`). High-DPI, дизайн «Контур» (слоновая
кость + графит), все разделы: Сводка / Реестр / Приоритет / Люди /
Руководители / Активность / Подключение.

## Файлы

| Файл | Назначение |
|---|---|
| `pult.py` | Сам пульт (Tkinter): импорт/экспорт, разброс, роли, руководители, активность |
| `enrich.py` | **Обогащение реестра**: в живой файл дописываются только заполненные ботом кейсы и их столбцы визита; ничего не перезатирается, рядом создаётся резервная копия |
| `razbros.py` | Разброс кейсов по личным .xlsb сотрудников (Excel/COM), используется пультом и как CLI |
| `Пульт.bat` | Запуск без консоли (pythonw) |
| `настройки пульта.json` | Адрес/ключ сервера, последние папки — создаётся сам |
| `dist/`, `src-tauri/` | **Легаси** — старый Tauri-пульт (Rust). Не развивается; оставлен как референс дизайна |

## Выгрузка: обогащение и слепок

- **Обогащение реестров выездников** — главный путь. Выбираешь папку с
  республиками (та же, что для разброса), жмёшь «Кого обогащать?» — пульт
  показывает сотрудников с завершёнными визитами и их личные ФИО.xlsb,
  галочками выбираешь кого — и в каждый файл точечно дописываются кейсы
  его сотрудника. Маркер «кейс заполнен» — дата выезда (её ставит только
  миниапп при завершении визита); пишутся только столбцы формы визита
  (статус, с кем контакт, договорённость, кто на адресе, местоположение,
  цель приезда, комментарий + дата). Системные значения из импорта
  («Не обработан» и т.п.) в файлы не тащатся. Рядом с каждым изменённым
  файлом создаётся резервная копия. «Обогатить один файл…» — то же самое
  для одного выбранного файла (например, мастер-Хард.xlsb).
- **Реестр целиком** — новый xlsx-слепок БД сервера: типизированные
  даты/суммы, автофильтр. Для сверки; это слепок БД, а не твой файл.

## Зависимости

`pip install python-calamine openpyxl xlwings` + установленный Excel
(нужен для обогащения .xlsb и разброса). Сеть — стандартная библиотека.
