# Пульты 2 — устройство и контракт (29.09.2026)

## Слово владельца

- Пульт руководителя — внутри своего окна с браузерной графикой (Electron, как
  Hélène), не системный браузер и не Tauri.
- Вход один раз по ключу; токен этого компьютера живёт до отзыва и удаляется при
  первой попытке соединиться после отзыва.
- Тотальный редизайн на физике и графике Hélène (репозиторий Praxis, `desk/`,
  образец — Windows-версия) — для руководителей, аналитиков и миниаппа.
- Руководители: «сетка, как в миниаппе», разделение по офисам, статистика и
  главное — активность. Таджикистан: поборы «в счёт долга» — вход безопасникам и
  способ следить за сотрудниками.

## Оболочка `hard-desk/`

Electron 44, TypeScript + esbuild. Окно без рамки, свои кнопки; «свернуть» и
«закрыть» — к часам (трей), выход — из меню значка; один экземпляр; память окна.
Страница — протокол `hard://app`, строгий CSP, `contextIsolation`, `sandbox`.

Режим: `--analyst`, имя exe с «аналит», `HARD_MODE=analyst` или папка «Хард» внутри
комплекта (рядом `pult/desk_backend.py`) → пульт аналитика; иначе руководителя.

- **Руководитель.** Сеть только в главном процессе (`src/main/net.ts`), сессия
  `persist:hard-net` мимо прокси, сертификат — Chromium по хранилищу Windows.
  Токен и кэш экранов — зашифрованы `safeStorage` (DPAPI) в `%APPDATA%\Хард`.
- **Аналитик.** Дочерний `python -m pult.desk_backend` (127.0.0.1, случайный порт,
  секрет запуска в каждом запросе): контуры и токен устройства — `pult.core.api`,
  формулировки — `pult.core.*` по закрытому списку (`/fn`), реестр/обогащение/
  выгрузки — `pult/desk_registry.py`, долгое — задачей с журналом (`/job`).

Сборка: `npm run build`; поставка: `node tools/dist.mjs` → `dist/Хард` + `Хард.zip`.
Снимки для проверки глазами: `HARD_SHOTS=<папка>` (окно проходит разделы полки),
телефон — `tools/phone-shots.cjs` (`PHONE_BASE`, `PHONE_OUT`).

## Сервер

### Роли — `managers.role`

| роль | вход команды, план, привязки | «Контроль» | лента активности |
|---|---|---|---|
| `manager` (по умолчанию) | да | нет | да |
| `security` | только чтение (403 `read_only`) | да | да |
| `full` (и владелец ADMIN_ID) | да | да | да |

`/admin/manager` принимает `role`; без ключа роль не трогается.

### Вход пульта руководителя

- `POST /api/manager/device/enroll` `{code, device}` — код из ссылки входа
  руководителя (ссылка целиком или код). 200 `{token, device_id, me, caps}`;
  410 `link_dead`; 403 `not_manager` (ссылка выездника не тратится).
- `X-Pult-Token` принимается только на `/api/manager/*` и `/api/control/*`.
  Живой — `last_seen_at` раз в минуту; отозванный — строка УДАЛЯЕТСЯ, 401
  `device_revoked`; неизвестный — 401 `device_unknown`.
- `GET /api/manager/device/me`, `POST /api/manager/device/logout`.
- Аналитику: `GET /admin/manager_devices.json[?telegram_id=]`,
  `POST /admin/manager_device/revoke.json` `{id}` | `{telegram_id, all: true}`.
  Удаление руководителя удаляет его компьютеры; `/admin/app_revoke` (all) —
  отзывает.

### Активность — `GET /api/manager/activity`

Окно как у статистики (`preset/shift/from/to`), `office`, `employee`,
`kinds=visit,view,photo,login,mark,promise`, `before`, `limit`. Ответ: `offices`,
`employees` (выездов, первый/последний, далеко/позже/со следами, `last_seen`),
`events` (выезд: исход, договорённость, текст, вердикт у адреса, карточка за N с,
`flags`; журнал доступа: открыл карточку, фото, вход, метка, обещание).

### Контроль — `server/control.py`

Следы по выезду: `far`, `nogeo`, `late`, `fast` (<40 с), `night` (21–07),
`series`, `cash` (слова ru/tj/uz), `paid` («Оплачен», а платежа в реестре после
выезда нет, старше 3 дней). Риск человека — доли следов против медианы его офиса
(офис меньше трёх — вся команда), плюс счёт «наличных», «ездит без результата»
и неподтверждённого обзвона; `risk` 0–100, `level` low/mid/high.

- `GET /api/control/overview`, `GET /api/control/flags?employee=`,
- `GET /api/control/callbacks?date=` — выборка на день закрепляется в
  `control_checks`: до 10 выездов по следам + 10% случайных (не меньше 3),
- `POST /api/control/callback` `{visit_id, outcome, note}` —
  outcome: confirmed / no_visit / cash_to_employee / paid_elsewhere / no_answer /
  refused / wrong_number,
- `GET /api/control/export.xlsx` — «Риск» и «Обзвон», текст со «=» — текстом.

Все чтения ПД — в `audit`.

### Дев-стенд

`ADMIN_API_KEY=devmaster python server/pult_dev.py` — синтетическая команда
(три офиса и без офиса, выезды за две недели со следами), печатает ключи
руководителя, безопасника и директора. Пульт аналитика к нему —
`HARD_PULT_SETTINGS=<файл>` с контуром `http://127.0.0.1:8090`.
