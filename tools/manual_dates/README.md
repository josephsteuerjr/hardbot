# Даты сохранённых правок Excel

Python сравнивает сохранённые значения двух блоков строки. Дата записывается
после закрытия книги. Начальная калибровка не датирует старые строки. Макросы
и изменение настроек доверия Office не используются.

`build_bundle.py --output <локальный каталог>` готовит исходный Python-комплект
с перечнем SHA-256. При необходимости `--calamine-cp314 <локальный каталог>`
добавляет проверенную calamine для Python 3.14. Остальные версии Python могут
читать XLSB через установленный Excel. Требуются xlwings, pywin32, openpyxl;
для изменения XLSX — lxml, для существующих скриптов аналитика — pandas.
Фиксированные версии находятся в requirements проекта. Новая упаковка в EXE
не требуется. После изменения исходников комплект и manifest пересобираются.

Рядом со скриптами размещаются `rbr_manual_dates.py`, `rbr_edit_dates.py`,
`rbr-manual-dates-package.json`, каталог исходников и рабочий
`rbr-manual-dates.json`. Последний содержит `enabled`, `journal`, `books`,
`personal_roots`, `preferred_books`, `book_patterns`, `poll_seconds`.
Шаблон общего реестра поддерживает `{month_ru}`, `{month}`, `{year}`.
Предпочтительная книга задаётся полным путём и заменяет обычное имя в той
же папке. Архивные имена по маске не подбираются.

Первичный общий журнал и квитанции размещаются в явно выбранном рабочем
каталоге. Комплект копируется с проверкой SHA в профиль запускающего
пользователя. Excel-копии, SQLite и резервные копии остаются локально.
`prepare(paths)` обрабатывает сохранённые правки перед сборкой;
`staged_master(path)` готовит общий реестр локально;
`publish(target,candidate,expected_sha256)` проверяет исходник и подтверждает
программную запись в общем журнале. Снятые ответственные не восстанавливаются
из старых личных файлов; одинаковые КД разных партнёров не смешиваются.

Импорт helper запускает локальный фоновый Python-процесс. Блокировки профиля
и общего журнала ограничивают число наблюдателей. Для запуска при входе
пользователя используется `start_manual_dates.pyw`; он ожидает доступности
рабочего диска. Состояние — `%LOCALAPPDATA%/Hard/manual-edits/watch-status.json`.
Наблюдение не требует запущенного окна Аналитика.

Неизвестный день после перерыва между рабочими днями сохраняется для проверки,
новая дата не выдумывается. Открытая книга ожидает записи и останавливает
сборку до закрытия. Изменившийся исходник останавливает публикацию. Неизвестный
результат записи проверяется по квитанции до повторной попытки.
