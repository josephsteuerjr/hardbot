# Пульт «Контур · Выезды»

**Актуальный пульт — `pult.py` (Python/Tkinter).** Запуск: двойной клик
`Пульт.bat` (или `python pult.py`). High-DPI, дизайн «Контур» (слоновая
кость + графит), все разделы: Сводка / Реестр / Приоритет / Люди /
Руководители / Активность / Подключение.

## Файлы

| Файл | Назначение |
|---|---|
| `pult.py` | Сам пульт (Tkinter): импорт/экспорт, разброс, роли, руководители, активность |
| `enrich.py` | **Обогащение реестра**: в живой файл дописываются только заполненные ботом кейсы и их столбцы визита; ничего не перезатирается, рядом создаётся резервная копия |
| `razbros.py` | Разброс кейсов по личным .xlsb сотрудников (Excel/COM), используется пультом и как CLI |
| `Пульт.bat` | Запуск без консоли (pythonw) |
| `настройки пульта.json` | Адрес/ключ сервера, последние папки — создаётся сам |
| `dist/`, `src-tauri/` | **Легаси** — старый Tauri-пульт (Rust). Не развивается; оставлен как референс дизайна |

## Экспорт: два режима

- **Обогатить реестр** — главный путь. Выбираешь свой живой `Хард.xlsb`,
  пульт забирает данные с сервера и точечно дописывает ТОЛЬКО то, что
  заполнили выездники (их кейсы, их столбцы: статус, комментарии, даты,
  договорённости). Чужие строки/столбцы/листы/форматирование не трогаются.
- **Реестр целиком** — новый xlsx-слепок БД сервера (как в старом пульте):
  типизированные даты/суммы, автофильтр. Подходит для «чистой» выгрузки,
  но это именно слепок БД, а не твой файл.

## Зависимости

`pip install python-calamine openpyxl xlwings` + установленный Excel
(нужен для обогащения .xlsb и разброса). Сеть — стандартная библиотека.
