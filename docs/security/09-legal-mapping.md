# 15. Маппинг на 152-ФЗ / ZRU-547 / ТДж № 1537 + ISO 27001

> Не юридическая консультация. Финальная проверка — локальные юристы по каждой юрисдикции.

## 15.1. РФ — 152-ФЗ (ПД) + 230-ФЗ (взыскание)

| Требование | Реализация в системе | Статус |
|---|---|---|
| **Локализация** (ст.18(5)): первичная запись ПД граждан РФ — в БД на территории РФ | Он-прем (ПК аналитика / сервер филиала РФ); данные не уезжают | ✅ дизайн |
| С 01.07.2025 — запрет использования зарубежных БД | Свой геокодер/тайлы; никаких Google/Yandex-облаков как ядра | ✅ дизайн (🟡 включить свой геокодер на PROD) |
| Согласие на обработку | Организационно (оператор/принципал) | 🔴 процедурно |
| Регистрация оператора в РКН (`pd.rkn.gov.ru`) | Организационно | 🔴 процедурно |
| Журналирование доступа к ПД | `audit` (каркас) | 🟡 → SIEM/tamper-evident |
| Уведомление об утечке ≤24 ч | IR-план (§12) | 🟡 регламент |
| **230-ФЗ: ≤1 визита/нед на должника** | Killer-фильтр в `scoring` (`MIN_DAYS_BETWEEN_VISITS=7`) | ✅ |
| **230-ФЗ: часы будни 08–22 / выходные 09–20** | Окно VROOM `planner._day_window` (env может только сузить) | ✅ |
| 230-ФЗ: хранение записей 1.5 года | Retention (§11) | 🟡 формализовать |
| 230-ФЗ: двойное согласие на контакт с 3-ми лицами | Организационно + поля карточки | 🔴 процедурно |

## 15.2. Узбекистан — ZRU-547 (ПД)

| Требование | Реализация | Статус |
|---|---|---|
| Локализация (ст.27-1): ПД граждан УЗ — в стране | Он-прем в филиале УЗ (принцип «данные не уезжают») | ✅ дизайн |
| Спец-закона о поведении взыскателя нет | Принят внутренний стандарт = числа 230-ФЗ | ✅ (как контроль) |

## 15.3. Таджикистан — Закон № 1537

| Требование | Реализация | Статус |
|---|---|---|
| Локализации ПД нет, но нужна **сертификация средств защиты** у регулятора | Он-прем; перечень средств защиты к сертификации — организационно | 🔴 процедурно |
| Спец-закона о взыскании нет | Внутренний стандарт (230-ФЗ как бенчмарк) | ✅ |
