# Контур · Выезды — кратко, по конкретике

### Аналитический движок выездного взыскания: скоринг «куда выгоднее ехать» → маршрут → сбор данных → аналитика

> Версия для аналитика: что считаем, по какой формуле, что на выходе. Без маркетинга.
> **Живое демо (синтетика, без ПД):** `https://kontur.166.88.185.90.nip.io/`

---

## 1. Задача одним абзацем

Выездник работает холодный портфель должников. Раньше точки расставляли руками в Google My Maps. Движок делает это автоматически: **скорит** каждого должника по выгоде визита, **строит порядок объезда** по реальным дорогам, **заставляет заполнить карточку** на выезде (данные копятся), и даёт **аналитику** офису. Всё на своём сервере, ПД не уезжают.

## 2. Скоринг «куда выгоднее ехать» (ядро)

На каждого человека считается приоритет 0–130:

```
score = 100 · ( w_долг·f_долг + w_кластер·f_кластер + w_свежесть·f_свежесть )
        + сигналы_дожима                          ← затем killer-фильтры обнуляют недосягаемых
```

| Признак | Как считается | Смысл |
|---|---|---|
| `f_долг` | `log10(1+долг) / log10(1+макс_долг)` | лог — чтобы один гигантский долг не забивал шкалу |
| `f_кластер` | `точек_в_городе / макс_по_городам` | один выезд закрывает плотную пачку рядом |
| `f_свежесть` | `1 / (1 + число_прошлых_выездов)` | не долбить тех, к кому уже ездили |

**Веса `w_*` крутит оператор** под регион (в РФ важнее «сговорчивость», в разведке ТДж — «кластер+долг»).

**Два режима** (портфель холодный — о клиенте часто ничего не известно):
- **РАЗВЕДКА** (нет исхода прошлого визита) — цель добыть данные: долг × кластер × свежесть.
- **ДОЖИМ** (исход есть) — добавляются сигналы из карточки:

| Сигнал | Поправка |
|---|---|
| обещает оплатить | **+12** |
| на родине (для курьера ТДж) | +8 |
| проживает клиент по адресу | +6 |
| нет контакта | −6 |
| передана информация 3-му лицу | −8 |

**Killer-фильтры** (снимают из очереди сегодня):
- по исходу: `оплачен · смерть · тюрьма · кредит не брал · адрес не существует`;
- курьер ТДж: `клиент в РФ / в другой стране` → недосягаем;
- **регуляторные (230-ФЗ):** визит был <7 дней назад → отложить (≤1 визит/нед); обещанная дата в будущем → ждать дату.

Все коэффициенты — в одном файле (`scoring_config.py`), прозрачно и под ревью.

## 3. Маршрут (что делает карту «автоматической»)

Скоринг говорит *кого*, маршрутизатор — *в каком порядке*:
- **VROOM** (решатель VRP) поверх **OSRM** (реальные времена по дорогам). Фолбэк, если что-то недоступно: гео-кластеризация k-means + 2-opt + расстояние по прямой.
- **Раздача на бригаду** из N выездников с балансировкой нагрузки.
- На выходе по каждому маршруту: порядок точек, **км**, **минуты**, **сумма долга**, и **доходность = долг ÷ минуты** — прямой аналитический показатель «отдача маршрута».

## 4. Маховик данных (двигатель проекта)

```
холодный портфель → выезд → ОБЯЗАТЕЛЬНО заполнить карточку (иначе визит не закрыть)
        ▲                                          │
   скоринг точнее ◄── данные копятся в БД ──────────┘
        └────── через N тысяч визитов → модель «вероятность оплаты» (ML)
```

Сейчас — **эвристика с весами** (ML рано: нужны исходы «заплатил/нет» через 30–60 дней, портфель пока холодный). Это сознательное решение, не недоделка.

## 5. Аналитика для офиса

Тот же движок даёт «вид сверху»: тепловая карта кластеров долга, доходность маршрутов (долг/мин), разбивка разведка/дожим, конверсия по выездникам. Отдельный продукт писать не нужно — это агрегаты тех же данных.

## 6. Почему это не игрушка (для аналитика)

- **Ниша пустая:** связку «скоринг → гео-кластер → маршрут → офлайн-полевое приложение» под СНГ не закрывает никто; ближайший аналог — индийский Credgenics. Скоринговый финтех из Таджикистана **Zypl.ai** скорит только на выдаче — стадия взыскания свободна.
- **Под наукой:** правильное правило выезда — по ожидаемой ценности `P(оплата|визит) × возврат ≥ стоимость визита`; наш показатель «долг/мин» — его рабочий зачаток.
- **Возможность:** публичного исследования «выезд против звонка» не существует — через маховик + A/B (champion-challenger) компания может получить это доказательство первой.
