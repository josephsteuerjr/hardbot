# engine/web — дашборд движка

**Источник истины — `dashboard_template.html`. Правьте только его.**

| Файл | Роль |
|---|---|
| `dashboard_template.html` | ✏️ ИСТОЧНИК ИСТИНЫ. Вся вёрстка/логика дашборда здесь. Плейсхолдер `/*__DATA__*/` — куда подставляются данные. |
| `dashboard.html` | 🤖 ГЕНЕРИРУЕТСЯ из шаблона командой `python engine/build_demo.py`. **Руками не редактировать** — затрётся при следующей сборке (вверху файла стоит баннер-предупреждение). |
| `data.json` | 🤖 Данные дашборда (синтетика), пишет `build_demo.py`. |
| `vector_check.html` | Мини-страница проверки вектор-PMTiles. |

Поток: `build_demo.py` → синтетика → скоринг (`scoring.score_items`) → маршрут (`routing`) →
подстановка в шаблон → `dashboard.html` + `data.json`.
`app/main.py` отдаёт `dashboard.html` на `/`; данные для живых ползунков — через `/api/*`.
