# Постоянные режимы импорта Аналитика

В версии 3.2.15 полный срез выбранных сотрудников, возврат ручных снятий и
применение проверенных офисных правок Софта включены постоянно. Переключатели
удалены. Обработчик предпросмотра применяет те же правила при старом запросе,
в котором опции отсутствуют или содержат false.

Замена текущих комментариев выезда в начале месяца остаётся отдельной опцией,
снятой по умолчанию. Выбор сотрудников и типа импорта, исключения договоров,
точный исходный файл и состояние этой опции связаны с предпросмотром.
Применение использует подтверждённый состав эффектов сервера. Изменение
обязательных режимов не запускает импорт автоматически.

История доставки в личные книги распознаёт сетевой UNC-путь и соответствующий
ему подключённый диск как один существующий файл. При наличии двух записей
сохраняется последнее подтверждённое значение каждого поля. Решение по
конфликту также следует за физической книгой; другая книга с тем же именем
не получает чужое решение. Правки книги после подтверждённой доставки остаются
защищёнными обычным сравнением сервера, книги и истории доставки.
