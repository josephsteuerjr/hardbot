## Как внести изменения

Общий текст пары Word/PDF хранится в user.md и engineering.md. Исправьте нужную главу и запустите из этой папки следующие команды. Сборщику Word нужен Python с пакетом python-docx. Tectonic собирает PDF на движке XeTeX. На машине со стандартным XeLaTeX вместо Tectonic запустите xelatex дважды для каждого документа, чтобы разрешить ссылки оглавления.

```powershell
python build.py
tectonic CRM-SNG-User.tex
tectonic CRM-SNG-Engineering.tex
```

Для вёрстки используются Georgia, Calibri и Consolas. При их отсутствии шаблон выбирает семейства DejaVu. Исходники .tex можно править и компилировать отдельно. Для пользовательской книги сохраните рядом папку illustrations с двумя снимками учебного контура.

Проверьте страницы с командами и иллюстрациями, закладки и переходы из оглавления. Снимки пользовательской книги сделаны на SyntheticBackend из опубликованной сборки 7ba798597656d038.
