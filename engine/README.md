# Контур · Движок выездов (engine)

Аналитический движок поверх бота `hardbot`: **геокод → скоринг «куда выгоднее ехать» →
оптимальный объезд (VRP) → дашборд** для аналитика/руководства. Демо-центр проекта —
то, что должно «продать» систему руководству, **не сажая выездников на сырой продукт**.

## Что внутри
| Файл | Назначение |
|---|---|
| `geo.py` | Офлайн-геокодер (встроенный газеттир РФ/УЗ/ТДж + джиттер). Лёгкое ядро боевого слоёного геокодера |
| `routing.py` | VRP-лайт: матрица (гаверсинус или OSRM) → nearest-neighbour → 2-opt. Порядок объезда |
| `build_demo.py` | Сборка демо на **синтетике** (без ПД): генерит людей → скор → маршрут → `web/dashboard.html` |
| `app/main.py` | FastAPI-оркестратор: `/`, `/api/points`, `/api/route`, `/api/analytics`, `/healthz` |
| `web/dashboard_template.html` | Дашборд MapLibre («Контур», тёмная тема, живые веса, маршрут дня) |
| `Dockerfile`, `docker-compose.yml` | Контейнер движка (+ профиль `full` с PostGIS) |
| `deploy.ps1` | Деплой на лёгкий сервер (venv+uvicorn+systemd, через Posh-SSH) |

## Локально (на твоей машине)
```bash
python engine/build_demo.py            # → engine/web/dashboard.html (открыть в браузере)
# или поднять сервис:
pip install -r engine/requirements.txt
uvicorn app.main:app --app-dir engine --port 8090   # http://localhost:8090
```
Реальные данные: задать `HARDBOT_DB=путь\к\hardbot.db` — движок возьмёт людей из БД бота.
**Без `HARDBOT_DB` — синтетика** (ПД не участвуют).

## На сервер (1 vCPU / 3 ГБ)
```powershell
powershell -ExecutionPolicy Bypass -File engine\deploy.ps1
# доступ (порт наружу НЕ открыт): ssh -L 8090:127.0.0.1:8090 root@SERVER → http://localhost:8090
```

## Архитектура (жёсткое правило)
- **Сервер 166.88.185.90 (лёгкий, 24/7):** ТОЛЬКО синтетика — постоянная демонстрация готового комплекса руководству. **ПД здесь не бывает НИКОГДА** (`HARDBOT_DB` на сервере не задаётся; синтетика генерится на месте).
- **Твоя машина (мощная, Docker):** разработка + всё с реальными ПД + тяжёлые разовые сборки (PMTiles/Planetiler, дорожный граф OSRM/Valhalla). Реальные данные **не покидают ПК**.
- Деплой на сервер несёт только КОД. Реальные данные туда не уезжают по определению.
