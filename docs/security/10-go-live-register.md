## Что УЖЕ закрыто (для контекста ревью — не требует действий)

☑ Локализация ПД (он-прем, демо-сервер только синтетика) · ☑ initData HMAC + авторизация ·
☑ Аппрув привязки выездника · ☑ Аудит-лог доступа к карточке · ☑ Токен-auth на API движка +
hard-guard старта (реальная БД без токена / `0.0.0.0` → отказ) · ☑ Сужен CORS · ☑ Лимиты 230-ФЗ
в оптимизаторе · ☑ Единый скоринг/util/газеттир · ☑ Проект под git · ☑ pytest-набор зелёный
(99 тестов).

## Минимальный набор для go-live с реальными ПД

**Только P0:** пункты 1 (пентест), 2 (шифрование диска), 3 (свой геокодер), 4 (регистрации+согласия).
Остальное (P1/P2) — параллельно/сразу после, но не блокирует пилот на ограниченном круге.

> Этот реестр — живой. Владелец отмечает статусы по мере закрытия; при изменении системы
> синхронизировать с threat model ([04](04-threat-model-stride.md)) и контролями ([05](05-controls-rbac.md)).
