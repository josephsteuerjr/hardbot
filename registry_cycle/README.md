# Перенос реестров

Рабочий запуск: дважды кликнуть [Перенос реестров.pyw](../Перенос%20реестров.pyw) —
окно на PySide6 (Qt 6) без консоли. Окно цикла (`python -m registry_cycle gui`) —
[Хард — Реестры.pyw](../Хард%20—%20Реестры.pyw). Зависимости: `requirements-registry-cycle.txt`.

В одном окне находятся две независимые операции:

1. «Собрать в общий реестр» — личные `.xlsb` → общий реестр.
2. «Раздать в личные реестры» — свежий общий реестр → личные `.xlsb`.

Второй шаг не запускается автоматически. У каждого шага своя проверка, свой
план, подтверждение, архивная копия и квитанция.

## Основные правила

- Источники выбираются в приложении как корневые папки. Внутри берутся все
  группы, кроме папок архива.
- Рабочий формат — только `.xlsb`.
- Имя группы, папки и файла не определяет владельца и профиль.
- Владелец читается из `ответственный Сотрудник`; вниз попадают строки этого
  ответственного из общего реестра.
- HARD/SOFT определяется по составу и типам столбцов книги.
- Столбцы сопоставляются по заголовкам, а не по позиции.
- Существующий порядок и точный текст заголовков личной книги сохраняются;
  недостающий профильный столбец добавляется справа из общего вместе с типом
  и форматом. Неизвестный именованный столбец блокирует раздачу, а безымянный
  сохраняется по КД только в своей личной книге.
- Регулярных выражений и правил имён в приложении нет.

## Платежи

- `Сумма последнего платежа` и `Дата последнего платежа` принадлежат
  сотруднику: собираются вверх и сохраняются в его личном реестре.
- `Текущие платежи` и `Оплаты за …` принадлежат аналитикам и остаются только в
  общем реестре. Шаг 2 блокируется, если такие колонки попадут в личную
  проекцию.

## Безопасность

До подтверждения живые книги не меняются. Скрипт создаёт локальный snapshot,
план, Excel-staging и полную проверку. Табличные данные до и после staging
читаются через Calamine; отдельный скрытый экземпляр Excel используется только
для корректной записи `.xlsb` и проверки формул, форматов, листов и фильтров.
Открытые пользовательские процессы Excel не закрываются.

Форматы значений в строках проекции берутся по соответствующему столбцу общего
реестра: число не может случайно превратиться в дату из-за формата прежней
строки. Групповые фильтры Excel по датам восстанавливаются с тем же смыслом и
проверяются после сохранения.

Занятый целевой файл блокирует операцию. Sidecar-копии рядом с рабочими книгами
не создаются. Архивные пути и структура папок задаются в
[config/app.json](config/app.json); квитанции содержат SHA-256 исходника,
backup и опубликованного файла.

Подробный порядок — в [MANUAL_TRANSFER.md](MANUAL_TRANSFER.md).
