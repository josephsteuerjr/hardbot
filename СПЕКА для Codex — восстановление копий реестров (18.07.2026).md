# СПЕКА для исполнителя — восстановление копий личных реестров (18.07.2026)

## Контекст (зачем, в двух словах)

Телеграм-бот выездного взыскания до 18.07.2026 писал комментарий выездника не в ту
колонку — в «комментарий звонка». Обогащение разнесло эти тексты в личные реестры
сотрудников (`<ФИО>.xlsb`), затерев родные колл-комментарии. Родные тексты остались
только в резервных копиях этого компа/сервера. Задача исполнитель — **только достать из
бэкапов копии файлов нужных дат и сложить рядом**. Больше ничего: не менять, не
пересохранять, не открывать в Excel, живые файлы не трогать.

## Что восстановить

Личные реестры сотрудников. Живые лежат по маске:

```
<базовая папка>\Таджикистан\Портфели отдела взыскания РТ\<Город или Soft>\<ФИО>\<ФИО>.xlsb
```

Для каждого сотрудника нужна **последняя доступная копия, снятая СТРОГО РАНЬШЕ
его дедлайна** (дедлайн = момент, когда бот впервые сохранил его карточку; копия
раньше этого момента гарантированно не содержит бот-текстов):

| Сотрудник | Копия строго ДО |
|---|---|
| Ибрагимов Исмоил | 09.07.2026 06:18 |
| ГПХ Дмитриев Александр | 16.07.2026 11:05 |
| Хасанов Давирхон | 16.07.2026 12:08 |
| Джумаев Шерали | 17.07.2026 15:39 |

Если несложно — дополнительно по **ещё одной, более ранней** копии каждого файла
(страховка на случай, если «последняя до дедлайна» окажется битой).

Если копий личного файла за нужный период не существует (файл создан позже) —
вместо него восстановить копию **общего файла реестра** (источника разброса,
«Хард….xlsb» / файл, из которого делался импорт) с тем же правилом даты.

## Куда положить и как назвать

Папка (создать в корне базовой папки; восклицательный знак обязателен — пульт
такие папки игнорирует):

```
<базовая папка>\!восстановленные_бэкапы\
```

Имя файла — ФИО и момент, когда **бэкап был снят** (не момент восстановления!):

```
<ФИО> @ YYYY-MM-DD_HHMM.xlsb
пример: Джумаев Шерали @ 2026-07-17_0700.xlsb
```

## Отчёт

Рядом положить `отчёт восстановления.txt`: по строке на файл — что восстановлено,
из бэкапа какой даты/времени, полный путь источника в системе бэкапов. Если для
кого-то нет копии раньше дедлайна — явно написать, какие даты вообще доступны.

## Нельзя

- открывать/пересохранять восстановленные файлы (только копирование как есть);
- класть их в папки сотрудников или переименовывать живые файлы;
- запускать пульт / обогащение / разброс, пока идёт вся операция починки.

## Что будет дальше (для понимания, исполнитель это не делает)

Восстановленные копии используются ТОЛЬКО для чтения — из них возьмут колонку
«комментарий звонка» по номерам КД → вернут родные колл-тексты в базу бота →
бот-тексты переедут в «Комментарий текущего месяца выезда». Затем живые файлы
чинятся ТОЧЕЧНО и только по двум колонкам комментариев: ячейка «звонка»
правится лишь при побайтном совпадении с бот-текстом, ячейка «выезда»
заполняется лишь ПУСТАЯ; всё, что сотрудники писали в файлы руками, не
затирается — расхождения выводятся списком владельцу. Файлы целиком к прошлому
не откатываются.
