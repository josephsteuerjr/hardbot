# Сборка hard-pult.exe

Один бинарник пульта руководителя: без питона и Qt. Собирается на этой машине
GNU-тулчейном Rust — компилятор C не нужен (TLS через schannel, никаких
C-зависимостей вроде ring).

## Инструментарий (уже стоит)

- Rust: `cargo +stable-x86_64-pc-windows-gnu` (второй тулчейн рядом с msvc).
- Полный mingw-w64: `C:\mingw64\mingw64\bin` (gcc, ld, dlltool) — скачан с
  mingw-builds (16.2.0, posix-seh-ucrt). Бандл-компоновщик rustup неполный:
  его dlltool не умеет собирать импорт-библиотеки для windows-sys.

## Команды (Git Bash)

```bash
cd hard-pult
export PATH="/c/mingw64/mingw64/bin:$PATH"
export CARGO_TARGET_X86_64_PC_WINDOWS_GNU_LINKER="C:/mingw64/mingw64/bin/gcc.exe"
# Кириллица в пути проекта ломает GNU ld: target-каталог выносится в ASCII-путь.
export CARGO_TARGET_DIR="C:\\htarget"
cargo +stable-x86_64-pc-windows-gnu build --release
cp /c/htarget/release/hard-pult.exe .
```

Тесты — так же с `test` вместо `build --release`; smoke-тест бинарника:
`pytest tests/test_hard_pult_exe.py` (без exe честно пропускается).

## Грабли, уже закопанные

- **Kaspersky съедает сборки с `strip`+LTO** как «подозрительные» — файл
  исчезает через десятки секунд после сборки. Профиль релиза оставлен обычным
  (`opt-level = 2`, без strip/LTO); бинарник ~7 МБ — плата за спокойствие.
- `cargo check` без `CARGO_TARGET_DIR` в ASCII-пути падает на
  `cannot find ... .rlib: No such file` — это не отсутствующие файлы, это ld,
  не читающий кириллические пути.
- Страница пульта встраивается из `../pult_ruk/web/` (rust-embed): правки
  интерфейса делаются там, у бинарника своей копии нет.

## Что внутри

- `src/settings.rs` — те же настройки, что у питон-версии: файл JSON рядом с
  exe, серверы по адресам, токен только там.
- `src/hard.rs` — клиент «Харда»: кэш экранов, устаревшие данные при обрыве,
  повтор без проверки сертификата для самоподписанного прода, без системных
  прокси.
- `src/session.rs` — код-пропуск телефона, ПИН, пять промахов гасят тоннель.
- `src/tunnel.rs` — cloudflared как подпроцесс (без окна).
- `src/server.rs` — локальный API и страница (та же, что у pult_ruk).
